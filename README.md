# 🎙️ Text-to-Speech Generator

A Python-based Text-to-Speech Generator that converts written text into natural-sounding speech using Google's Text-to-Speech (gTTS) library.

This project allows users to enter text and convert it into an MP3 audio file.

## 🚀 Features

- Convert written text into speech.
- Supports English language.
- Generate audio in MP3 format.
- Simple and beginner-friendly interface.
- Save generated speech as an audio file.

## 🛠️ Technologies Used

- **Python** – Programming language.
- **gTTS** – Google Text-to-Speech library.
- **MP3** – Audio output format.

## 📋 Requirements

- Python 3.x
- Internet connection
- gTTS library

## ⚙️ Installation

**1. Clone this repository**

```bash
git clone https://github.com/Casanovaaa0/text-to-speech-generator.git
```

**2. Navigate to the project directory**

```bash
cd text-to-speech-generator
```

**3. Install the required library**

```bash
pip install gTTS
```

## ▶️ How to Run

Run the Python program using:

```bash
python main.py
```

Enter the text you want to convert into speech when prompted.

The generated audio will be saved as:

```text
output.mp3
```

## 📂 Project Structure

```text
text-to-speech-generator/
│
```

## 💡 How It Works

1. The program asks the user to enter text.
2. The gTTS library processes the entered text.
3. The text is converted into English speech.
4. The generated audio is saved as `output.mp3`.
